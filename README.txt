Московский Политех — scroll transition

1. Распакуйте архив.
2. Не перемещайте scene-1.png и scene-2.png отдельно от index.html.
3. Откройте index.html в современном браузере.
4. Для разработки удобнее запускать через Live Server в VS Code.

Финальные состояния используют исходные референсы напрямую,
поэтому логотипы, текст, красная точка и композиция совпадают с макетами.
Canvas используется только для перехода между ними.
